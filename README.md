# 👾 ASCII.VIBES - Animated ASCII Art Experience

A lightweight, zero-dependency animated ASCII art synthesizer. Features real-time 3D projection, procedural effects, vintage CRT emulation, and customizable phosphor themes.

## ✨ Features
- **🍩 3D Torus (Donut):** Classic mathematical ray-illumination donut projection in pure ASCII.
- **🧊 3D Wireframe Cube:** Rotating 3D hypercube with depth sorting and edge rasterization.
- **⚡ Matrix Digital Rain:** Authentic glyph waterfalls with glowing trail leaders.
- **🌀 Warp Tunnel:** Hypnotic infinite tunnel vortex.
- **🌊 Sine Wave:** Multi-frequency wave interference simulation.
- **📺 Retro CRT Emulation:** Authentic scanlines, vignette curvature, and flicker toggle.
- **🎨 Color Themes:** Phosphor Green, Vintage Amber, Cyberpunk Cyan, Synthwave, and Monochrome White.
- **⚡ Zero Build Step:** 100% static HTML/CSS/JS. Instant load, zero dependencies.

## 🚀 Deployment
Deployable in 1 click to [Vercel](https://vercel.com) or GitHub Pages.
